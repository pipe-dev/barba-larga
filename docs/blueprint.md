# **App Name**: Barba Larga AppointMe

## Core Features:

- Date Selection: Enable users to select a date for their appointment using a calendar interface.
- Dynamic Time Slot Display: Show available appointment times based on the selected date.
- Client Information Input: Capture client's name and email to collect reservation information.
- Appointment Booking: Allow users to book an appointment and to save the user's inputs with the desired appointment date in the 'pending' list. Firebase functions and Firestore will be set up to perform data validation.
- Service Catalog Display: Show the services offered, including descriptions and prices, in a carousel format.
- Interactive Map Integration: Integrate a map and navigation link showing directions to 'Barba Larga'.
- AI-Powered Style Recommendations: The system will start by identifying a client's gender identity and act as a tool to make haircut, beard, facial mask treatment, and coloring/straightening recommendations and, finally, suggesting particular service options that best fits the advice given.

## Style Guidelines:

- Primary color: Rich brown (#A67B5B), evoking classic barbershop tones and sophistication.
- Background color: Light tan (#F5E7DE), a desaturated tone similar to the primary color to provide a neutral, warm backdrop.
- Accent color: Deep red (#8B0000), for a pop of traditional contrast.
- Body text: 'PT Sans', a humanist sans-serif for a modern, slightly warm and inviting feel; great for UI text
- Headline text: 'Playfair', a high-contrast modern serif, suitable for a high-end brand impression
- Use vector icons for services, map markers, and sound controls. Icons should match the primary color when active.
- Use a clean, grid-based layout. Service Catalog can be horizontally scrollable.
- Subtle transitions when navigating between time slots, service catalog items, or map views.
